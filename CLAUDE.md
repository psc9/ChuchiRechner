# Regeln für dieses Repo (ChuchiRechner)

- Sprache: Schweizer Hochdeutsch (kein ß), Du-Form.
- Die App läuft als Web-App auf GitHub Pages und wird auf dem iPhone über den Home-Bildschirm genutzt (Patrick und Caro).
- Versionen: Die aktuelle Version steht oben in `index.html` im Kommentar `<!-- ChuchiRechner · Version X.Y · TT.MM.JJJJ -->`. Bei jeder Änderung die Version hochzählen (z. B. 1.0 → 1.1; grosse Umbauten 2.0), das Datum anpassen und nach dem Push ein Git-Tag `vX.Y` setzen.
